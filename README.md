# Gerência de Configuração

Este repositório reúne os materiais, exercícios e anotações desenvolvidos durante a disciplina de **Gerência de Configuração**, ministrada no meu curso de graduação.

## ⟡˖ Objetivo

O objetivo deste repositório é acompanhar a evolução do aprendizado sobre ferramentas e práticas utilizadas no gerenciamento de configuração de software, registrando atividades realizadas ao longo da disciplina.

## ⟡˖ Conteúdos

Durante a disciplina, serão abordados temas como:

- Versionamento de código
- Git
- GitHub
- Branches

> Esta lista será atualizada conforme novos conteúdos forem sendo apresentados em aula.

## ⟡˖ Organização

Os arquivos e atividades estarão organizados por assunto ou por aula, facilitando a consulta e o acompanhamento da evolução dos estudos.

## ⟡˖ Finalidade

Este repositório possui finalidade exclusivamente acadêmica e serve como registro das atividades desenvolvidas durante a disciplina.
